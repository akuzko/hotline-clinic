# Hotline Clinic: Delegation Plan

> Lesson 01 (Delegation), Deliverable 2. Modes: **Automation** means AI does it and I check. **Augmentation** means we work it out together. **Agency** means AI works freely inside boundaries I set.

| Capability         | Mode                                | What AI does                                                                                                                              | What I own                                                                                                                                                                            |
| ------------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Empathy**        | Augmentation                        | Questions the scope, points out users I missed (caregivers, reception), catches terminology traps ("therapist" → _general practitioner_). | Standing in the patient's place. The reframe from _wait time_ to _guaranteed nearest slot_. Choosing the three urgent areas.                                                          |
| **Design**         | Augmentation                        | Proposes flows, layouts and copy variants. Drafts the emergency notice and error messages. Flags accessibility issues.                    | Choosing by _situation_ (Injury / Sick child / Feeling unwell) instead of by specialist title. Tone, final copy, what the patient sees first.                                         |
| **Architecture**   | Augmentation                        | Researched stacks. Proposed SSE + Postgres LISTEN/NOTIFY, database-level protection against double booking, and the hold/expiry model.    | Choosing the stack (TypeScript: Fastify + tRPC + Postgres + React). The rules that must always hold: no double booking, holds expire, no-shows free the slot, no medical data stored. |
| **Implementation** | Agency                              | Claude Code builds from the technical spec in a plan → approve → build → review loop, writing tests first from the acceptance tests.      | The boundaries: the agreed stack only, no new dependencies or schema changes without approval, every acceptance test turned into an automated test, migrations reviewed by me.        |
| **Judgment**       | Augmentation (AI advises, I decide) | Runs tests, reviews code (concurrency, security, rate limits), lists risks.                                                               | Deciding when it's good enough. Running the lesson 03 user test (no explaining, no helping) and checking it against all five lenses. What ships and what gets cut.                    |
| **Shipping**       | Automation                          | Writes the Dockerfile, CI, Render config and seed data. Runs deploys and smoke tests.                                                     | Production secrets, choosing the SMS provider, data retention settings, and the final go/no-go.                                                                                       |
